# 🔬 Pandemic Intelligence & Zoning System

### **Overview**
A professional Decision Support System (DSS) built to forecast pandemic trends and automate regional safety protocols. This tool uses mathematical modeling to turn raw data into actionable zoning strategies.

### **🌟 Key Features**
*   **SEIR Modeling:** Numerical integration of differential equations via `SciPy` to simulate disease spread.
*   **Dynamic Zoning Engine:** Automatically categorizes regions into **Red, Orange, or Green zones** based on 7-day rolling averages.
*   **Geospatial Mapping:** Interactive visualization of healthcare infrastructure in **Navi Mumbai** using `Folium`.
*   **Predictive Backtesting:** Validation layer comparing theoretical models against historical data points.

### **🛠️ Tech Stack**
- **Python** (Pandas, NumPy, SciPy)
- **Streamlit** (User Interface)
- **Folium** (Mapping)
